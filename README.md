# autogrid —— Live2D ArtMesh 自动布点

从 `.cmo3` 工程里读出每个 ArtMesh 的图片，**自动布一套网格顶点**，导出成图片 + JSON。
纯几何算法，不需要训练、不上传任何东西。

## 怎么用

**最简单**：双击 `自动布点.bat`（也可以把 .cmo3 文件或文件夹直接拖到它上面）。
默认读 `输入\` 目录里的 .cmo3，结果写到 `输出\`。

**命令行**：
```
python -m autogrid.cli <输入...> --out 输出目录
```
输入可以是 .cmo3、单张 PNG、或整个目录；可以给多个。

| 参数 | 作用 |
| --- | --- |
| `--out 目录` | 输出目录（默认 `_out`） |
| `--budget N` | 强制每个部件用 N 个顶点（不给就按内容自适应） |
| `--limit N` | 每个输入最多处理 N 个部件（快速试跑用） |
| `--min-visible N` | 可见像素少于此数的部件跳过（默认 16） |
| `--ppv N` | 老口径：每个顶点摊 N 像素（越小越密） |

## 输出什么

每个部件三样东西：

- `<部件名>.overlay.png` —— 原图上叠画好的绿色网格线，肉眼检查用
- `<部件名>.json` —— `vertices`（像素坐标，原点左上，跟 PNG 1:1）、`triangles`（顶点索引）、覆盖率/外溢率指标
- `sheet.png` —— 所有部件拼一张缩略图，一览

## 算法怎么布点

看 alpha 通道，只关心「哪里是不透明的内容」：

1. `content = alpha > 4`（阈值取 4 不是 0，滤掉生成图层的不可见噪声底）
2. 掩码向外膨胀 3 px —— 否则边缘三角形会被裁掉，部件边缘留白缝
3. 取所有轮廓（外轮廓 + 孔洞），按弧长分配边界顶点
4. 内部撒抖动格点
5. Delaunay 三角化，丢掉质心落在内容外的三角形
6. **覆盖补齐**：只要还有可见像素没被网格盖住，就在漏洞处补顶点重新三角化，直到覆盖率 ≥ 0.999

### 顶点数是怎么定的

从 758 个真实 ArtMesh（两个 Live2D 模型）反推建模师自己的习惯：**布点间距随部件变大而变松**。

| 轮廓总长 | 建模师实际间距 |
| --- | --- |
| 41–197 px | 8.2 px / 顶点 |
| 197–392 px | 12.0 px / 顶点 |
| 392–687 px | 15.1 px / 顶点 |
| 687–1112 px | 23.8 px / 顶点 |
| 1112–8098 px | 24.6 px / 顶点 |

拟合结果：`间距 = min(24.6, 0.75 × √轮廓总长)`，成块部件再用 `0.40 × √面积` 兜底。

## 实测效果（758 个真实部件）

| | 覆盖率 均值 | 覆盖率 第5百分位 | 覆盖率 最差 | 外溢率 均值 | 顶点数 中位 |
| --- | --- | --- | --- | --- | --- |
| autogrid | **0.9997** | 0.9992 | 0.9758 | **0.1745** | 48 |
| 建模师手布 | 0.9210 | 0.4505 | 0.0481 | 0.3906 | 30 |

只看建模师自己盖得好的那 619 个部件（公平对比）：覆盖率 0.9998 对 0.9999 打平，
**外溢率 0.195 对 0.404 —— 网格比手工布点贴合一倍**（96% 的部件更贴合）。

覆盖率 = 可见像素被网格盖住的比例，越低部件越容易被切掉；外溢率 = 网格落在空白处的比例，越低越贴形状。

## 模块

| 文件 | 作用 |
| --- | --- |
| `autogrid/mesh.py` | 核心：自动布点算法（`auto_mesh` / `suggest_budget`） |
| `autogrid/metrics.py` | 质量指标：覆盖率、外溢率、三角形质量 |
| `autogrid/caff.py` | 解析 .cmo3 的 CAFF 容器（文件表 + XOR 去混淆 + deflate） |
| `autogrid/cmo3.py` | 从 main.xml 取「图片 + 建模师网格」，`load_parts()` |
| `autogrid/cli.py` | 命令行入口 + 出图 |

## 已知限制

- `.cmo3` 里纹理的逻辑页尺寸取自 `GTexture2D` 的 `transformImageResource01toLogical01` 缩放。
  绝大多数部件是 `图宽/m00 = 逻辑页宽`，个别部件（如图比逻辑页还大）另有偏移，这类样本覆盖率会偏低。
- 网格是标量算法、没有语义：它不知道哪根是发丝、哪块是眼睛，只保证盖住 + 贴边。
- 顶点数比建模师略多（中位 48 对 30），方便后续手工删点。

## 学你风格的布点模型（可选，双击「智能布点.bat」）

用你自己 7 个模型导出的 **7768 个部件**训练的小模型（7.8M 参数，RTX 5080 上跑 46 分钟）。
它看的 10 路输入：纹理 RGB、边缘强度、内部纹理线、alpha、到轮廓的距离、**深度图**（用 Depth-Anything-V2 按画面明暗推的浮雕深度）、
以及「期望顶点数 / 名义点距」两个常数平面；输出一张「顶点该放哪」的热力图，再从热力图上取点。

三角形仍然交给几何代码（Delaunay + 裁剪 + 覆盖补齐），所以模型再怎么错也不会吐出坏网格。

**用法**：双击 `智能布点.bat` —— 和「自动布点.bat」完全一样（往「输入」里丢 .cmo3 或 .png，结果在「输出」）。
第一次会慢十几秒，因为要加载深度估计模型。

### 实测（125 个**没参与训练**的部件，顶点数一样多）

数值 = 到对方最近顶点的平均距离 ÷ 名义点距，越小越像；「→他」= 我们的点离他的点多远，「他→」= 他的点离我们的点多远。

| 方法 | →他 | 他→ | 外溢率 | 覆盖率 | 最小角中位 |
| --- | --- | --- | --- | --- | --- |
| 纯几何算法 | 0.710 | 1.225 | 0.152 | 0.977 | 33.0° |
| 贴线版（25%） | 0.701 | 1.231 | 0.152 | 0.976 | 32.4° |
| **风格模型（模型直接吐的点）** | 0.631 | **0.920** | — | — | — |
| **风格模型（过一遍几何收尾）** | **0.621** | 1.261 | **0.044** | 0.902 | 26.3° |

差距多大：**正向他好 11%，反向他好 25%** —— 就是说「他放点的地方，模型基本都放了点」，这是纯几何算法做不到的。
外溢率只有几何算法的 **29%**（0.044 对 0.152），网格贴形状更紧。
开上工具的覆盖补齐后（生产默认）：模型 0.671 / 1.151 / 0.984 / 0.045，几何 0.697 / 1.176 / 0.9995 / 0.152 —— 模型两项都略好，但要多花约 30% 顶点才补到同样覆盖。

**短板（照实说）**：模型吐的点会**扎堆**（热力图上哪里亮就挤哪里），所以要补覆盖得比几何算法多用点；
不补覆盖时覆盖率 0.902 对 0.977、最小角 26.3° 对 33.0°，都不如几何算法。**目前的最佳用法 = 模型定点 + 打开覆盖补齐**。
